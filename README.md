# NEWHINDIMOVIES — Wapka Movie Catalogue Theme

A mobile-first Wapka movie/file catalogue theme designed for authorized content and file-indexing use.

## Included

- Responsive NEWHINDIMOVIES theme
- Trending / Most Viewed banner — 5 items
- 16:9 trending slider with 6-second auto-scroll
- Featured Movies — 2 items
- Quality badge from `VAR(q)`
- Latest Releases — 20 items per page
- Pagination
- Category and sub-category support
- Browse Categories without repeated headings
- Existing Wapka File Lister / Folder Lister logic preserved
- Existing `%name%`, `%id%`, `%thumb%`, `%filenum%`, `%q%` variables preserved
- Mobile-first blue/white UI
- Responsive movie cards
- Existing download/category URL patterns retained

## Wapka installation

1. Open your Wapka theme/import area.
2. Import `theme/NEWHINDIMOVIES_WAPKA_THEME.json`.
3. Review the Wapka variables and URL paths for your own site.
4. Test the homepage, category pages, sub-categories, pagination and download pages.
5. Publish only content/files you are authorized to distribute.

## Important

This repository contains a theme/interface and Wapka configuration. It does not contain copyrighted movie files.

Do not use the project to distribute copyrighted material without permission.
