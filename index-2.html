What's included

Built around the existing Wapka logic

The project focuses on improving presentation and usability while preserving the important Wapka listing, category, pagination and variable-based systems.

🔥

Trending Movies

Top 5 most-viewed movies in a responsive 16:9 banner with touch scrolling and 6-second auto-scroll.

⭐

Featured Movies

Exactly 2 featured movies with quality displayed dynamically using the existing VAR(q) logic.

🆕

Latest Releases

20 movies per page with Wapka-compatible pagination and newest-first listing.

📂

Categories

Main categories and sub-categories are supported without repeated Browse Categories headings.

📱

Mobile First

Responsive cards, spacing and navigation designed primarily for Android and mobile browsers.

⚙️

Wapka Variables

Existing variables such as %name%, %id%, %thumb%, %filenum% and VAR(q) remain part of the theme logic.
