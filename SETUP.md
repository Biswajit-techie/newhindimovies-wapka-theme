# Setup Guide

## 1. Import the theme

Use:

`theme/NEWHINDIMOVIES_WAPKA_THEME.json`

as the primary Wapka theme/configuration file.

## 2. Verify homepage

Check:

- Trending — 5 most-viewed items
- 16:9 banner
- 6-second auto-scroll
- Featured Movies — 2 items
- Latest Releases — 20 per page
- Pagination
- Browse Categories

## 3. Verify category pages

Check:

- Category heading appears once
- Sub-categories appear when present
- Movie cards use the existing Wapka variables
- Pagination works
- Footer stays below the content

## 4. Before production

Test on:

- Android Chrome
- Desktop Chrome
- Firefox
- Safari
- Slow mobile connection

Also verify that every URL and file being linked is authorized for distribution.
